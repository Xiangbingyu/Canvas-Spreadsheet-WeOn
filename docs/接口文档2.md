## 通用约定

- 这 4 个接口均为 WebSocket 消息，不提供 HTTP 版本。
- 所有请求都必须先通过 `join` 加入目标文档房间。
- 发送方当前 socket 绑定的 `clientId` 必须与消息中的 `clientId` 一致，否则返回 `4003`。
- 行列下标均为 `1-based`。
- 插入行列表示插入空白行列，不会自动创建新单元格。
- 删除行列会删除目标行列上的单元格，其余单元格按规则整体平移。
- 任意一次结构变更成功后，都会清空该文档下所有用户的后端 `undo/redo` 栈，因此成功响应中的 `canUndo` 和 `canRedo` 固定为 `false`。

### 成功消息通用格式

```json
{
  "type": "响应类型",
  "code": 0,
  "message": "ok",
  "data": {}
}
```

### 错误消息通用格式

```json
{
  "type": "error",
  "code": 4000,
  "message": "错误描述",
  "data": null
}
```

### 业务码

| 业务码 | 含义 |
| --- | --- |
| 0 | 成功 |
| 4000 | 参数错误 / 业务规则不满足 |
| 4003 | 未 join 文档或 `clientId` 与当前 socket 身份不匹配 |
| 4004 | 文档不存在 |
| 5000 | 服务器内部错误 |

## insert_row — 插入空白行

在指定工作表的目标行之前插入一行空白行。

### 请求消息

```json
{
  "type": "insert_row",
  "docId": "doc_sys_001",
  "clientId": "user_001",
  "sheetId": "sheet_20260527_001",
  "row": 3
}
```

### 请求字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| type | string | 是 | 固定值 `insert_row` |
| docId | string | 是 | 文档 ID |
| clientId | string | 是 | 操作用户 ID |
| sheetId | string | 是 | 目标工作表 ID |
| row | number | 是 | 1-based 行号，允许范围 `1 <= row <= rowCount + 1` |

### 处理语义

- 在第 `row` 行之前插入一行空白行
- 所有 `cell.row >= row` 的单元格整体下移一行
- `rowCount += 1`

### 成功广播

消息类型：`row_inserted`

```json
{
  "type": "row_inserted",
  "code": 0,
  "message": "ok",
  "data": {
    "docId": "doc_sys_001",
    "clientId": "user_001",
    "sheetId": "sheet_20260527_001",
    "seq": 12,
    "row": 3,
    "canUndo": false,
    "canRedo": false
  }
}
```

### 广播字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| docId | string | 文档 ID |
| clientId | string | 操作用户 ID |
| sheetId | string | 实际写入的工作表 ID |
| seq | number | 本次操作的序列号 |
| row | number | 实际插入位置的 1-based 行号 |
| canUndo | boolean | 恒为 false |
| canRedo | boolean | 恒为 false |

删除指定工作表中的目标行。

### 请求消息

```json
{
  "type": "delete_row",
  "docId": "doc_sys_001",
  "clientId": "user_001",
  "sheetId": "sheet_20260527_001",
  "row": 3
}
```

### 请求字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| type | string | 是 | 固定值 `delete_row` |
| docId | string | 是 | 文档 ID |
| clientId | string | 是 | 操作用户 ID |
| sheetId | string | 是 | 目标工作表 ID |
| row | number | 是 | 1-based 行号，允许范围 `1 <= row <= rowCount` |

### 处理语义

- 删除第 `row` 行
- 目标行上的单元格被删除
- 所有 `cell.row > row` 的单元格整体上移一行
- `rowCount -= 1`

    "seq": 13,
    "row": 3,

| clientId | string | 操作用户 ID |
| sheetId | string | 实际写入的工作表 ID |

## 错误消息

### 参数缺失

行操作：

```json
{
  "type": "error",
  "code": 4000,
  "message": "docId, clientId, sheetId and row are required",
  "data": null
}
```

列操作：

```json
{
  "type": "error",
  "code": 4000,
  "message": "docId, clientId, sheetId and col are required",
  "data": null
}
```

### 工作表不存在

```json
{
  "type": "error",
  "code": 4000,
  "message": "sheet not found: sheet_missing_001",
  "data": {
    "docId": "doc_sys_001",
    "sheetId": "sheet_missing_001"
  }
}
```

### 未 join 或身份不匹配

```json
{
  "type": "error",
  "code": 4003,
  "message": "socket has not joined this document as the specified client",
  "data": null
}
```

插入行：
