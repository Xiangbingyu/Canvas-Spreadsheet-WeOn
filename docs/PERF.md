# PERF

## **测试环境**

- 浏览器：Microsoft Edge版本 129\.0\.2792\.52 \(正式版本\) \(64 位\)

- 设备：Win 11

- DPR：1920\*1080

## **字段说明**

- 平均 render\(ms\)：测试期间每次 `renderGrid` 的平均耗时。

- 最大 render\(ms\)：测试期间最慢一次 `renderGrid` 的耗时。

- render 次数：测试期间触发 Canvas 绘制的次数。

- Long Task：测试期间浏览器主线程超过 50ms 的长任务记录。

- 更新响应耗时\(ms\)\-endToEndMs：从提交操作开始到 Canvas 绘制完成的总耗时

- Canvas 绘制耗时\(ms\)\-renderMs：更新触发的 Canvas 绘制耗时
