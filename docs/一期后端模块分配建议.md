# 第一期后端模块分配建议

## A 负责什么

A 负责：

- HTTP：
  - `POST /docs`
- WebSocket：
  - `set_cell`
  - `import_sheet`
- 内存结构：
  - `docs`
  - `snapshot`
  - `seq`
  - `history`

也就是说，A 主要负责“文档内容本身”的创建和修改。

对应文件：

- `backend-js/routes/docs.js`
- `backend-js/store/docsStore.js`
- `backend-js/store/memory/docsMemoryStore.js`
- `backend-js/ws/handlers/setCell.js`
- `backend-js/ws/handlers/importSheet.js`

## B 负责什么

B 负责：

- HTTP：
  - 无核心模块
- WebSocket：
  - `join`
  - `presence`
- 运行时结构：
  - `roomUsers`
  - `roomSockets`
  - socket 断开清理
  - 房间广播

也就是说，B 主要负责“房间连接、在线用户、广播协同”。

对应文件：

- `backend-js/ws/index.js`
- `backend-js/ws/dispatcher.js`
- `backend-js/ws/handlers/join.js`
- `backend-js/ws/handlers/presence.js`
- `backend-js/store/roomUsersStore.js`
- `backend-js/store/roomSocketsStore.js`
- `backend-js/store/memory/roomUsersMemoryStore.js`
- `backend-js/store/memory/roomSocketsMemoryStore.js`

## 公共文件

这些文件尽量少改，或者先一起定一次：

- `backend-js/app.js`
- `backend-js/server.js`
- `backend-js/routes/health.js`
- `backend-js/utils/response.js`

## 最终建议

最推荐的分工就是：

- A：`POST /docs` + WebSocket `set_cell` / `import_sheet`
- B：WebSocket `join` / `presence` + 房间连接与在线用户管理

这样分工最直观，也最不容易冲突。
