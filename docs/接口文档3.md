# `set_range_values` 接口文档

## 1. 语义

- 用途：一次提交一批逐格不同的单元格更新，适用于批量粘贴、批量改值、批量改样式、批量撤销/重做回放。
- 特点：整批在一次文档锁和一次事务内原子完成，只生成一个 `seq`。
- 样式：采用样式池化，消息里通过 `styles + styleId` 传递样式。
- 与现有接口关系：
  - `set_cell`：单格更新
  - `batch_set_cell`：一批坐标共享同一个 patch
  - `set_range_values`：一批坐标各自拥有独立 `value/styleId`

## 2. 请求

### 2.1 消息结构

```json
{
  "type": "set_range_values",
  "docId": "doc_sys_001",
  "clientId": "user_001",
  "sheetId": "sheet_20260527_001",
  "baseSeq": 12,
  "styles": {
    "s_abc": { "bold": true, "bgColor": "#2563eb", "color": "#ffffff" },
    "s_def": { "italic": true }
  },
  "cells": [
    { "row": 2, "col": 2, "value": "姓名", "styleId": "s_abc" },
    { "row": 2, "col": 3, "value": "年龄", "styleId": "s_abc" },
    { "row": 3, "col": 2, "value": "张三" },
    { "row": 3, "col": 3, "value": "28", "styleId": "s_def" },
    { "row": 4, "col": 2, "styleId": null }
  ]
}
```

### 2.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `type` | string | 是 | 固定值 `set_range_values` |
| `docId` | string | 是 | 文档 ID |
| `clientId` | string | 是 | 必须与当前 socket 绑定的 `clientId` 一致，否则返回 `4003` |
| `sheetId` | string | 是 | 目标工作表 ID |
| `baseSeq` | number | 否 | 客户端发起本次写入时所见的文档最新全局 `seq`；建议新客户端都传 |
| `styles` | object | 否 | 样式池，键为 `styleId`，值为样式对象 |
| `cells` | array | 是 | 非空逐格数据列表 |

### 2.3 `cells[]` 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `row` | number | 是 | 1-based 行号，正整数 |
| `col` | number | 是 | 1-based 列号，正整数 |
| `value` | string | 否 | 缺省表示保留原值；传 `""` 表示清空为空字符串 |
| `styleId` | string \| null | 否 | 缺省表示保留原样式；传字符串表示应用样式池中的样式；传 `null` 表示清空样式 |

### 2.4 请求语义

- 只传 `value`：只改内容
- 只传 `styleId`：只改样式
- 同时传 `value + styleId`：值和样式一起覆盖
- `value` 与 `styleId` 都不传：非法，返回 `4000`
- `cells[].styleId` 为字符串时，必须满足：
  - 在本次请求的 `styles` 中存在对应项，或
  - 已存在于当前文档目标 sheet 的样式表中
- 若同名 `styleId` 已存在于文档样式表中，但内容与本次 `styles[styleId]` 不一致，建议返回 `4000`

## 3. 响应

### 3.1 成功响应

```json
{
  "type": "range_values_updated",
  "code": 0,
  "message": "ok",
  "data": {
    "docId": "doc_sys_001",
    "clientId": "user_001",
    "sheetId": "sheet_20260527_001",
    "seq": 17,
    "styles": {
      "s_abc": { "bold": true, "bgColor": "#2563eb", "color": "#ffffff" },
      "s_def": { "italic": true }
    },
    "cells": [
      { "row": 2, "col": 2, "value": "姓名", "styleId": "s_abc" },
      { "row": 2, "col": 3, "value": "年龄", "styleId": "s_abc" },
      { "row": 3, "col": 2, "value": "张三" },
      { "row": 3, "col": 3, "value": "28", "styleId": "s_def" },
      { "row": 4, "col": 2, "value": "", "styleId": null }
    ],
    "canUndo": true,
    "canRedo": false
  }
}
```

### 3.2 响应字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `docId` | string | 文档 ID |
| `clientId` | string | 操作用户 ID |
| `sheetId` | string | 实际写入的工作表 ID |
| `seq` | number | 本次整批操作分配的全局序列号 |
| `styles` | object | 本次 `cells` 实际引用到的样式池 |
| `cells` | array | 应用后的逐格最终结果 |
| `cells[].row` | number | 实际写入的 1-based 行号 |
| `cells[].col` | number | 实际写入的 1-based 列号 |
| `cells[].value` | string | 最终写入后的值 |
| `cells[].styleId` | string \| null | 最终写入后的样式引用；`null` 表示无样式 |
| `canUndo` | boolean | 当前操作后操作者是否可撤销 |
| `canRedo` | boolean | 当前操作后操作者是否可重做 |

### 3.3 响应语义

- 返回的是最终结果，不是原始请求 patch
- 若目标坐标发生 transform，返回 transform 后的最终坐标
- 发送方会收到一条 `reply` 和一条同 `seq` 的广播，客户端可继续用 `seenSeqs` 去重

## 4. 错误码

| 码 | 场景 |
| --- | --- |
| `4000` | 缺字段、`cells` 为空、单元格 patch 无效、坐标非法、引用未知 `styleId`、样式池冲突 |
| `4003` | `clientId` 与 socket 绑定不一致，或未 join 该文档 |
| `4004` | 文档不存在 |
| `4090` | `baseSeq` 冲突，或中途遇到 `import_sheet` barrier |
| `5000` | 服务端内部错误 |
